검증 결과 및 근거

판정마다 근거를 함께 표시합니다.
사실 오류는 확인 요청, 근거가 없는 항목은 확인불가로 표시합니다. CNO는 확인되지 않은 값을 만들지 않습니다.
오류등록값이 서로 충돌 확인 요청담당 확인 후 수정 경고표기·규칙 정리 확인불가근거 없음, 값 생성 안 함 확인규칙·DB와 일치
검증 기준

CPU 상품명 · 보존 모드
데스크톱 모델명 (코드네임) (판매구성), 서버 모델 Processor (xC, yT, zM Cache, a.bc GHz) 형식은 그대로 둡니다. 상품명은 자동 수정하지 않고 사실 오류만 확인 요청합니다(상품명 수정은 담당 승인 사항).

코드네임은 정식 명칭, 띄어쓰기 표기. 예 랩터레이크 리프레시 사파이어 래피즈

부가제목 ※ 쿨러 포함/미포함 | ※ A/S n년 — 쿨러는 판매구성에 명시된 경우만 포함, A/S는 확인된 경우만 표기.

키워드 모델명 우선, 쉼표 뒤 공백 없음. 포괄어(게이밍·하이엔드 등)·유통어(벌크·정품 등) 제외. 다른 모델 번호 혼입 탐지.

중요요약설명 CPU는 사양 DB에서만 생성합니다. DB 값은 Intel 공식 사양 페이지와 개별 대조한 모델과 대조 전 모델(F·KF 파생 등)을 구분해 표시하며, 미등록 모델은 값을 만들지 않습니다. 모니터는 기존 값을 표준 순서·표기로 정렬만 합니다.

캡처 인식은 브라우저 내 OCR로 모델 번호와 판매구성을 읽습니다. 인식 결과는 상품명 칸에서 원본과 대조해야 하며, 나머지 필드는 DB·규칙으로 생성됩니다.
